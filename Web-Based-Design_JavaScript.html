jQuery Interactive Playground

Click panels to slide up/down, or drag the green card vertically.

1. Slide Up and Down Panels

Uses jQuery's .slideToggle() method.

jQuery animates the height of this element smoothly between 0px and its full height when clicked.
You can pass "slow", "fast", or any number in milliseconds (like 400) to control the slide speed.
A callback function can run right after the sliding animation finishes—for example, rotating the arrow icon!

2. Vertical Dragging

Uses jQuery UI's .draggable() constrained to the Y-axis.
